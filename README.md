# MIXER by Sanusi

Audio Studio Mixer untuk GitHub Pages.

## Upload
Upload `index.html`, `manifest.json`, `sw.js`, `icon.svg` ke root repository, lalu Commit changes. Aktifkan GitHub Pages dari branch `main` jika belum aktif.

## Fitur
- Import beberapa audio lokal.
- Channel terpisah: volume, pan, bass, mid, treble.
- Mute, Solo, Play/Pause.
- Master output dan perekaman hasil mix ke WebM/Opus jika didukung browser.

Audio diproses lokal di browser. Format audio dan perekaman bergantung dukungan browser/perangkat.
